# SideTrack

Track and MIDI editing tools for REAPER - a companion to [SideFX](https://github.com/Conceptual-Machines/SideFX).

## Features

### MIDI Velocity Curve Editor
Draw velocity curves using bezier handles - similar to the SideFX curve editor but for MIDI data.
- Apply smooth velocity ramps to selected notes
- Exponential, logarithmic, and S-curve presets
- Visual feedback in velocity lane

### Grid Quantization Menu
Quick access popup menu for grid quantization settings.
- All standard grid divisions
- Triplet and dotted options
- Single toolbar button trigger

### Bitwig-Style Note Operators (Planned)
Transform MIDI data using bezier curve-based operators:
- Velocity transforms (exponential progressions)
- Note multiplication/division
- Interval transformations
- Pattern generation

## Installation

1. Clone this repo to your REAPER Scripts folder
2. Or add via ReaPack (coming soon)

## Requirements

- REAPER 7.0+
- ReaImGui (for curve editor UI)
